A security-focused vulnerability scanner that combines **deterministic analysis** with optional **AI explanations**.

**Highlights**

* Deterministic security scanning
* AI-assisted vulnerability explanations
* JSON and SARIF reporting
* Rescan and baseline comparison
* GitHub Actions integration

### 🔐 [Secure-Case](https://github.com/Ashish-Netam011/Secure-Case)

A secure digital document management system designed for **legal and investigation documents**.

**Highlights**

* Document integrity verification
* Role-based authorization
* Access requests and controlled document access
* Audit events and versioning
* PII redaction
* AI-assisted document analysis

> AI is used as an advisory layer, not as a legal conclusion.

**Highlights**

* Deterministic analysis first
* Passive URL analysis
* Evidence-based results
* Optional AI explanations
* OCR-based investigation workflow
